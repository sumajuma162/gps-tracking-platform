# GT06 trackers

GT06 is a protocol used by Concox GT06 and many compatible trackers. The platform implements it from the published
GT06 protocol document as a gateway plugin (`gateway/gpsgw/protocols/gt06/`). Clones differ: **verify behaviour
with your device** (Part D of the master spec).

## Setup

1. **Trackers → Add tracker**, model *GT06 (generic)*, the 15-digit IMEI.
2. Configure the tracker by SMS (typical clone syntax, **verify with your manual**):
   ```
   APN,internet#
   SERVER,0,gps.example.co.tz,5023,0#      (0 = domain; last 0 = TCP)
   TIMER,30#                               (upload interval when moving)
   ```
3. Port **5023/TCP** must be open.

## What is decoded

| Packet | Handling |
| --- | --- |
| 0x01 login | BCD IMEI; ACK only for registered trackers (others go to Unregistered devices) |
| 0x12, 0x22 location | time, satellites, latitude/longitude (/1,800,000), speed, course, hemisphere and GPS-fix bits, cell info; 0x22 adds ACC (ignition), re-upload flag and mileage |
| 0x13 heartbeat | terminal info (ACC, charging, GPS tracking), voltage level, GSM level; ACKed |
| 0x16, 0x26 alarm | a location plus status and an alarm code (SOS, power cut, vibration, overspeed, ...); ACKed |
| others | skipped without closing the session |

The seeded IO profile (`gt06-generic`) maps ignition, GSM level, battery level (0-6 scaled to %), odometer (from
mileage) and alarms (`sos`, `power_disconnected`, `vibration`, `device_overspeed`, `towing`). Adjust it in the IO
mapping editor for your device.

## Clock

Some clones send local time instead of UTC. Set **Time offset (minutes)** on the device model (e.g. 180 for EAT) and
the gateway corrects every record.

## Troubleshooting

- *No login ACK*: the IMEI isn't registered, or the tracker sends a different identifier format (check
  Unregistered devices).
- *Connection closed with `crc_mismatch` in the logs*: not GT06 framing, or a different CRC variant; capture raw
  packets and compare with the protocol document.
- *Positions in the wrong hemisphere*: some clones invert the latitude bit; report it with a raw packet.
